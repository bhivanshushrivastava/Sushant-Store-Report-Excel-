# Sushant Store Data Analysis

## Project Overview
This project analyzes **Sushant Store’s sales data** to uncover performance trends, customer behavior, and product profitability.  
The goal is to design a **dashboard** that highlights KPIs and provides actionable insights for better decision-making.

---

## Dataset
- **Source**: Sushant Store sales records (Excel file).
- **Fields**: Date, Product, Category, Quantity, Price, Discount, Customer ID, Region.
- **Granularity**: Transaction-level data.
- **Purpose**: To measure sales, profitability, and customer engagement.

---

## Dashboard & KPIs
### KPIs
- Total Sales Revenue  
- Average Order Value (AOV)  
- Gross Margin %  
- Top-Selling Products & Categories  
- Customer Count & Repeat Rate  
- Inventory Turnover  

### Dashboard Layout
- **Top Row** → KPI Cards (Revenue, Margin, Orders, Customers)  
- **Left Panel** → Category-wise bar chart  
- **Right Panel** → Trend line chart (sales over time)  
- **Center** → Pie chart (discount vs full-price sales)  
- **Bottom** → Filters (Date, Category, Region, Customer type)

---

## Key Insights & Observations
- Category trends: Which categories dominate revenue.  
- Seasonality: Identify peak months/days.  
- Discount effectiveness: Do discounts boost sales or hurt margins?  
- Customer segmentation: Loyal vs one-time buyers.  
- Profit drivers: High-margin vs high-volume products.  

---

## Learning & Conclusions
- **Learning**: Data cleaning, KPI modeling, and visualization are essential for clarity.  
- **Conclusions**:  
  - Discounts may drive volume but reduce margins.  
  - Certain categories/products consistently outperform.  
  - Repeat customers are crucial for sustainable growth.  
  - A well-structured dashboard turns raw data into actionable insights.
